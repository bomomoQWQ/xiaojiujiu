# 新测试者说明（模板）

给新测试者发一段**短的**说明。太长没人看；关键是三件事：她是谁、她会主动找你、怎么让她停。

发送方式（以 bot 身份，走她已经连着的那条 QQ 链路）：

```bash
bash scripts/announce_to_testers.sh "<下面这一段>" <新测试者的QQ>
```

正文（可直接复制，约 200 字）：

```
「新朋友须知」我是苏清徽。三件事说清楚：
一、我会记得你说过的话——这个记忆只属于你，不会跟别人混在一起。
二、我会自己想起你，可能主动给你发消息。不想被主动打扰就直接说「今天别联系我」或者「以后别联系我」，我会照做；直接拉黑也行。
三、我在测试期，偶尔会说错话、记错事。碰上了骂我两句就好，或者告诉馍馍。
说完这些，我们聊点别的吧。
```

按需替换的变量：

| 位置 | 说明 |
|---|---|
| 「馍馍」 | 你的对外称呼（现在是「博馍馍」，announce 正文里也用过这个名字） |
| 三条内容 | 若这轮封测**不**允许主动打扰，把第二条删掉，别只改措辞 |

要不要发的判断：

- **要发**：测试者是自愿来陪聊的、知道这是个 AI 角色、会在意"她记不记得我"。
- **不要发**：把这段当"功能说明"发出去只会让人先看规则再说话 —— 说明的**目的**是让对方知道
  "被主动找是设计的一部分，而不是 bug"，以及"停下来的方法真的有效"。

配套的两条硬事实（发给对方之前自己先确认一遍）：

1. **停下来的方式真的有效**：`authorize.py` 对明确声明的边界是硬拦（`boundary_blocks_proactive`），
   与人格画像无关；`boundaries.detect_boundaries` 现在**只允许延长、不允许缩短**用户声明的窗口
   （2026-09-18 修：`br=0.05` 曾把「今天不要主动联系我」的 24h 压成 20.76h）。
2. **记忆是每人一份**：一个实例一个 `companion.sqlite3`，互不可见；清库/搬运都是按人做的。
