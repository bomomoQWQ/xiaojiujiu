## 4. v2 生产行为基线

### 决策

- `runtime_v2.py::decide_endogenous`
- 资格：`not blocked && net_utility >= utility_threshold`
- 冷启动：安全探索，滚动 24h 三次、至少间隔 8h，探索优势下限 2.0。
- 选择：eligible 中 `argmax(net_utility)`。
- 触发：`λ = 3e-5 × softplus(4 × D)`；`p = 1-exp(-λΔt)`；`draw < p` 才提交。
- 典型实测：`D=2.0`、`λ=0.00024001006219118688`、`Δt≈900s`、`p≈0.1943`。
