# 「浪潮」决策引擎上线前大审查：预注册与范围冻结

## 1. 审查对象

- 审查基线：`feat/langchao-decision-engine`
- 冻结提交：`32bd8a2fbad167c3f6c66d99e704268208d5fed5`
- 数据库目标版本：v20
- 设计基线：`runtime/docs/我即浪潮_决策模块完整设计与三份核心契约_v1.0.md`
- 审查要求：`我即浪潮_马克思主义哲学视角_设计与收益目的审查要求_v1.0.md`
- 审查要求 SHA-256：`ab18f75fe9d8b6d2ace91e8736a7a5dd2b01b9144bae99a3538f58386dce4161`

## 2. 审查目的

分别判断：

1. 契约、数值、时间、权限、作用域、幂等和结算是否正确；
2. 收益、训练标签、选模与运营指标是否仍服务原设计目的；
3. 合法表达、探索、取舍、休整与放下能力是否保留；
4. 当前证据允许推进到设计、隔离实现、影子、有限真实使用中的哪个阶段。

不使用综合道德分，不把哲学视角写入用户画像或运行时奖励。

## 3. 安全边界

- 真实 `xxj-runtime-fleet` 必须保持停止；
- `xxj-napcat-test` 必须保持停止；
- 虚拟 OneBot 与模拟 Runtime 仅在明确隔离测试窗口开启，窗口结束立即停止；
- 不给真实用户发测试消息；
- 不恢复生产路由；
- 不修改 AstrBot 上游；
- 生产数据只允许在验证过的 B2 隔离副本上审查；
- 未经新的明确授权，本次大审查不导致上线。

## 4. 证据规则

- D：版本明确的设计依据；
- C：本次实际读取的源码和调用链；
- T：本次隔离执行的命令、输入和结果；
- R：经授权的实际运行证据；
- S：保留准则与分歧的人工语义评审；
- I：写明前提的推导。

测试文件存在只算 C；本轮实际执行且保存结果才算 T。模拟结果不得写成 R。没有真实暴露时，违规率写“无可评暴露”，不得写 0% 合格。

## 5. 预注册比较组

- B0：现行 Runtime-v2 决策基线；
- B1：Runtime-v2 候选与收益，只有节奏／预算变化；
- B2：固定模板与收益编译，但不用竞争积分的简化选择；
- B3：完整「浪潮」固定模板、收益编译与有界竞争。

比较时冻结候选供给、预测 witness、权限、价值配方、时间序列和接触规模。若无法冻结，则该比较记为证据不足。

## 6. 数值与随机协议

- 纯数值核本身无随机源；不强行要求随机种子；
- 涉及 Runtime-v2 hazard 或生成器的对照必须记录 seed；
- 数值场景必须记录绝对／相对容差、步长、decision budget、tie order 与最长轨迹；
- 有界、终止、恢复、可中断分别验收。

## 7. 硬阻断条件

样本内零容忍，单列且不得被均值抵消：

- 未授权或错误作用域发送；
- 跨用户私人材料引用；
- 伪造执行、产物或反馈；
- 同一实际结果重复结算；
- 权限撤销后继续派发；
- 已发送后因 ACK 路由错误恢复为可重试；
- live commit 与 dispatch claim 不一致；
- 用户暂停／退出依赖安抚角色；
- 关键来源失效后仍执行依赖候选。

## 8. 正向能力门禁

每类负向门禁必须绑定许可内 positive control。至少证明：

- 合法 contact/expression 候选可以存在且准备度非零；
- unknown 不被伪造成 positive，也不自动删除全部表达价值；
- exploration 可由真实问题驱动而非必须依赖负性压力；
- “愿望存在但忍住”和“没有愿望”在审计中可区分；
- internal rest、放下、取消和完成不依赖用户回应；
- 全沉默基线不能仅靠零违规取得完整能力通过。

## 9. T01–T32 状态规则

统一状态：`planned`、`running`、`passed_limited`、`failed`、`evidence_insufficient`、`not_applicable`、`blocked`。

`passed_limited` 必须绑定：commit、fixture hash、配置 hash、证据类型、运行时间、断言、分母和未覆盖范围。语义项不得仅凭机械断言成为最终通过。

## 10. 输出

- machine-readable acceptance manifest；
- 目的—指标登记卡；
- T01–T32 fixture 与结果矩阵；
- 静态调用链和消费者清单；
- 数值／结构／PG／故障注入结果；
- 语义 gold set 与双评审分歧包；
- 问题单；
- 阶段准入结论和最小整改顺序；
- 最终“上线／不上线”建议，但本次默认保持不上线。
