## 6. 上线阻断项

以下任一未完成前不得上线：

1. 在隔离环境构造有资格的 external candidate，使「浪潮」真实越过阈值，完成：contract validation → live claim → attempt → render → send → success/failure ACK → v19 terminal settlement → restart recovery。
2. 对上述链做真实 PostgreSQL 故障注入，证明 callback 尾部、claim、attempt、outbox、snapshot 任一点失败均全事务回滚；外部已发送后的 ACK 不会因路由错误回滚成可重试。
3. 在生产 B2 副本上运行真正的 pure-assess + shadow 重新执行，而非仅 persisted audit replay；覆盖 11 用户并报告候选 coverage、语义 agreement、defer agreement、unknown rate 与 boundary leak=0。
4. 在可用 PostgreSQL 测试环境运行所有 optional PG integration，包括 v20 FK、并发 ACK、authority CAS 和 live transaction backend/session 一致性。
5. 完成一用户、一 scope、发送速率为 1 的真实低风险 canary，人工确认后才允许扩大；本报告不批准该步骤。
