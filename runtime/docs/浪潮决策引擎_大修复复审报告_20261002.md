2. capability/task/artifact exact witness 已接入 Runtime reducer、Langchao live 与 exploration；完成声明优先使用权威 render metadata 和 semantic review，缺失或 unknown 时 fail closed。

5. reply/continuation/negative 用户观察已进入 v23 actual/correction OutcomeToken；标签和 OutcomeToken 指针共享事务，observer 失败整体回滚。
6. `langchao/shadow` authority 独立执行纯评估 + shadow runner，不触发 v2 commit。
7. permission projection、统一 no-send taxonomy、撤权无 claim/outbox、重开 fresh round 且不继承 readiness 已接线。
8. finite goal completion/drop/reopen 已有显式生产事件入口，goal/candidate/matter 同事务更新。
9. exploration 只接受可信 work/artifact witness，固定过程价值上限，不按时长/token/call 增殖，且不外发。
10. attention/competition 已支持 off/B2/B3 版本化 recipe；B3 需精确 scope allowlist，默认仍 off。
11. canonical requirement ID/crosswalk 已消除裸 Txx 题义串线。
